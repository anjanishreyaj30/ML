Why Ward Linkage?

Agglomerative clustering starts with each player as its own cluster. At every step, Ward linkage merges the two clusters that increase total within-cluster variance the least. This produces compact, roughly equal-sized clusters — a fair match for K-Means, so comparing them is meaningful.

Problem Statement

Coaches need to group cricket players by performance to pick teams, plan training, and spot players who need improvement. This project uses two unsupervised ML algorithms — K-Means and Ward Hierarchical clustering — to discover natural groupings and lets you compare them.

Objectives

Clean & scale player dataStandardScaler
Choose k sensiblyElbow + Silhouette
Run K-MeansCentroid clustering
Run Ward HierarchicalDendrogram-based
Compare the twoPCA + ARI
Auto-label clustersRule-based on centroids
Export resultsCSV download

ML Concepts Demonstrated

StandardScalerMean-0, std-1 normalisation so all features contribute equally to distance.
K-MeansMinimises inertia by alternating assignment and centroid update.
Ward LinkageMerges clusters to minimise growth in within-cluster variance.
Elbow + SilhouetteTwo complementary heuristics for choosing k.
PCAProjects 6 features to 2 components for visualisation.
Adjusted Rand IndexAgreement between two labellings, corrected for chance.
